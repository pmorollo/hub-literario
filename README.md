# Hub Literário

Projeto educacional independente para estudo de Literatura no Ensino Médio, ENEM e vestibulares.

## Princípio
O Hub Literário complementa, mas não substitui, a leitura integral das obras.

## Percurso
**Preparação → Leitura → Compreensão → Aprofundamento → Revisão → Teste**

## Obra-modelo v1.0
**Dom Casmurro — Machado de Assis**

Este repositório é um site estático em HTML/CSS, pronto para hospedagem em GitHub Pages. O domínio definitivo ainda não foi definido; canonical e sitemap com URLs absolutas devem ser adicionados após a definição do endereço público.


## Ambiente de staging
A versão preparada para validação no GitHub Pages usa `noindex, nofollow`. Antes da publicação definitiva, definir o endereço público, adicionar canonical/og:url/sitemap absolutos e então alterar a diretiva de indexação para `index, follow`.
